# College Enquiry Chatbot using Ollama

## Project Overview
The College Enquiry Chatbot is an AI-powered application designed to answer student queries related to college information using a Large Language Model (LLM).

## Features
- AI-powered question answering
- College-specific information retrieval
- Natural language interaction
- Simple and user-friendly interface

## Technologies Used
- Python
- Ollama
- Large Language Models (LLM)
- Streamlit (if used in the application)

## Project Structure
- `app.py` – Main application
- `college_info.txt` – College information and knowledge source
- `requirements.txt` – Python dependencies
- `test_gemini.py` – Model testing script
- `.gitignore` – Files excluded from Git

## Installation and Execution

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Ensure Ollama and the required model are installed and running, if applicable.
5. Run the application:

```bash
python app.py
```

## Purpose
To provide students with quick and convenient access to college-related information through an AI chatbot.
